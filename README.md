# Sawyer's Movies

A simple static movie-catalog website.

## Files
- `index.html` — page structure
- `styles.css` — design and responsive layout
- `movies.js` — searchable movie catalog

## Run it
Open `index.html` in a browser.

## Customize
Edit the `movies` array in `movies.js` to add/remove titles.

This starter uses poster placeholders and does not contain unauthorized movie files or links. Replace placeholders with artwork you have permission to use and add links only to lawful sources.
